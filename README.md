# Projeto de Xadrez em Java

## Descrição

Este projeto é uma implementação do clássico jogo de **xadrez** utilizando a linguagem de programação **Java**. O objetivo do projeto é criar um jogo de xadrez completo, com regras de movimento das peças e detecção de xeque/xeque-mate.

## Funcionalidades

- Movimento de peças de acordo com as regras oficiais do xadrez
- Validação de movimentos (restrições como movimentos ilegais e xeque)
- Detecção de xeque e xeque-mate
- Opção para jogar contra outro jogador localmente
- Jogabilidade fluida e responsiva

## Tecnologias Utilizadas

- **Linguagem:** Java
- **Paradigma:** Orientação a Objetos
- **Controle de Versão:** Git
- **IDE Recomendada:** IntelliJ IDEA ou Eclipse
